# Skill: Ticket Lifecycle

1. Desk Lead opens ticket with unique ID `TF-YYYYMMDD-XX`.
2. Evidence packages attached.
3. Risk Manager sizes or vetoes and finalizes ticket parameters.
4. Human must reply with exact `approve TF-YYYYMMDD-XX`.
5. Only then does Execution send the exact order.
6. Execution returns fill/rejection + reconciliation.
7. Desk Lead closes ticket and logs outcome.

Any deviation from this sequence is out of scope.
